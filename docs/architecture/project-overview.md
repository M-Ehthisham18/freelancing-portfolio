# Project Overview

This document provides the overarching context and history of the StudioDev Portfolio project.
Graphify uses this to create `PROJECT_GOAL` and `PART_OF_SPRINT` relationships.

## Project Goals
1. **Professional Authority**: Establish a brand that signals high-end technical craftsmanship.
2. **Conversion**: Drive potential clients toward booking a free consultation.
3. **Performance**: Achieve a 100/100 Lighthouse score for performance and accessibility.
4. **AI-First Documentation**: Use a knowledge graph to maintain architectural memory.
